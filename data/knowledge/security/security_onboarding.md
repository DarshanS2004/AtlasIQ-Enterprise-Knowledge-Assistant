# Security Onboarding Standard

Every new employee must complete security onboarding within the first five business days.

Required controls:
- Enroll in multi-factor authentication before accessing customer systems.
- Complete secure coding and phishing awareness training.
- Review the data classification policy and sign the acceptable use standard.
- Managers must confirm least-privilege access before any production role is granted.

Escalation:
- Any delayed completion beyond day five is routed to Security Operations and the employee's director.
- Production access is suspended until required controls are completed.
